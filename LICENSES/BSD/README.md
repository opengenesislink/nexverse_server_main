# BSD licenses and notices

This directory centralizes standalone BSD license documents inherited from the OpenSimulator 0.9.3.0 source baseline.

The move is organizational only. It does not relicense any inherited code, remove any copyright ownership, or replace license headers embedded in source files.

## Files

- `OpenSimulator-0.9.3.0.txt` — OpenSimulator project BSD license (formerly `/LICENSE.txt`)
- `Aurora-Sim.txt` — Aurora-Sim BSD notice
- `CircularBuffer.txt` — CircularBuffer BSD notice
- `DotNetOpenid.txt` — DotNetOpenId BSD notice
- `GoogleProtoBuffer.txt` — Google Protocol Buffers BSD notice
- `libsl.txt` — libsecondlife / Second Life Reverse Engineering Team BSD notice
- `ODE.txt` — Open Dynamics Engine BSD notice
- `OpenJpeg.txt` — OpenJPEG BSD notice
- `Prebuild-BSD-and-MIT.txt` — Prebuild license file; primarily BSD with an additional MIT-licensed portion
- `TexturesAssetSet-skins.txt` — BSD licensing statement for the bundled skin assets

## Mixed-license documents

Documents that merely reference BSD material while also governing code under another license remain in their original third-party notice collection. Examples include DotNetZip and protobuf-net notices. This avoids incorrectly presenting mixed-license components as BSD-only.

## Source headers

BSD copyright/license headers embedded directly in inherited source files remain in place. They are not duplicated or removed by this directory reorganization.
